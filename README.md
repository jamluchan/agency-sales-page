# Local Growth Agency - Sales Page

A high-converting sales page for a local business growth agency offering:
- Website Development
- SEO (Search Engine Optimization)
- Google Maps Optimization
- GAI (Generative AI Search)
- Agentic AI Solutions
- Content Management (Video, Newsletters, Articles)
- Paid Advertising
- Copywriting
- Video Sales Letters (VSL)

## Deployment

This site is deployed on Vercel. Connect your GitHub repository to Vercel for automatic deployments.

## Local Development

```bash
npx serve .
```

Or simply open `index.html` in your browser.
